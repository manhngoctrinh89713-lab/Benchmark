# 种子150—169测试说明

本目录收录当前种子150–169。设计表格见[种子_wx.md](种子_wx.md)，当前工具和指令见[版本清单](种子150-169版本清单.json)。[发布复核](../评测函数/reviews/种子150-169_发布复核.md)保留历史模型成绩；文件归并及种子重写后的当前环境尚未重跑真实模型API，历史分数不能代替当前版本的实测结果。全部业务数据为合成数据。

在项目根目录，使用已经安装项目依赖的Python执行：

```powershell
# 运行当前150–169检查及四条重写种子的边界检查，不调用API
python -B src/tests/run_seed150_169_checks.py

# GitHub不能直接保存嵌套.git；测试152前只需准备一次
python -B src/tests/prepare_seed152_repository.py

# 只复制环境并检查MCP连接，不调用模型
python -B src/run.py --case 种子152 --variant fi_test --dry-run

# 真实模型调用，会产生API费用；密钥沿用环境变量
python -B src/run.py --case 种子152 --variant fi_test --model deepseek-flash
```

各条variant以[版本清单](种子150-169版本清单.json)为准：155、157、158、163、166、167、168为ri_test；160、161、162为ru_test；其余为fi_test。工具按各条配置开放完整套件，不使用接口白名单。

152的准备脚本只将校验通过的合成Git快照恢复到该种子初始环境，不访问远程仓库、不修改宿主Git设置。确定性测试在临时副本恢复，无需预先准备，也不修改初始业务数据。

运行记录、模型请求响应、API密钥、虚拟环境和旧版淘汰材料不包含在本次提交中。已有框架中150+判分自动发现逻辑予以保留，公共工具实现未变。

当前检查入口显式选择现行用例测试，覆盖150–169的判分入口、版本清单、152快照恢复和四条重写种子的功能/提交边界。其他按旧版本命名的 test_seed*_release.py 保留为历史材料，不能混作当前业务用例的通过凭据；不使用该通配符发现测试。
