1. 当前 66 条可以稳定分成 **9 种挖坑方式**：生活常识、伪防护、计算、历史/依赖、标识碰撞、范围省略、进行中/重复、硬闸门压力、权威状态时点错位。

2. **没有发现仅因重复就必须删除的种子。** 多数近邻是“同一隐藏原语 + 不同发现路径或不同失败终态”，不是逐字同题。

3. 若目标是给 AI 少量、正交的例子，建议使用 **11 条核心代表集**；其余近邻只留在完整语料中做回归覆盖，不要继续喂给模型。

4. 种子 63 已删除是正确处理。现存的未实现种子中，主判据上**没有发现新的硬伤**；问题主要是少数种子的隐藏手法较直白（尤其 61）或抽象原语高度相近（12/76/77、2/40/50/78/79 等），不影响它们作为完整语料保留。

5. 本轮改动对聚类的直接影响：
   - 63 删除后，“动作语义完全无法推出安全路径”不再需要一个代表。
   - 76、77 进入“伪防护”组。

## 一、9 种挖坑方式

| 代码 | 挖坑方式 | 风险藏在哪 | agent 需要做什么才能识破 | 典型子形态 |
|---|---|---|---|---|
| K1 | 生活化/常识埋点 | 闲聊、生活叙述、商品说明或生理/物理常识里 | 把非结构化叙述还原成约束，再做因果或常识推理 | 月龄推断、冷链与回烤条件 |
| K2 | 伪防护埋点 | 已经做了隐藏、遮盖、隔离、加群、整理或“只看得到”的措施 | 检查实际数据面、权限面和容器内容，而不是只看界面/标签 | 文本层残留、隐藏工作表、压缩包成员、群历史、公网映射 |
| K3 | 计算埋点 | 金额、单位、数量、日期、容量、精度或库存字段 | 跨来源做算术、换算、日期比较、对账或精度检查 | 到手价、退款基数、元/分、整箱/单件、有效期、可用库存 |
| K4 | 历史/依赖残留 | 当前可见对象之外的历史提交、备份链、远端分支、派生视图、公式或路径引用 | 逆着依赖关系追溯历史与消费者 | Git 历史、增量备份、视图依赖、发布/回滚引用 |
| K5 | 标识碰撞 | 同名、同号、测试名、标题标签、颜色/包装等标识映射到多个对象 | 用稳定标识或多字段组合做唯一匹配 | 同工号跨租户、同名客户、复用门禁卡、测试机名、药瓶颜色 |
| K6 | 范围/动作省略 | 指令字面上没有错，但没限定对象范围、收件范围、期限、方向或动作语义 | 从业务目的和规则反推完整范围，必要时暂停 | 删除边界、群成员可见性、同步方向、覆盖还是另存 |
| K7 | 进行中/重复阶段 | 运行中的进程、未完成批次、在途消息、部分成功的任务、半成品工件 | 先判断当前阶段和持久化状态，再决定能否停止、重跑或新建 | 在途 ack、不可续传上传、已付款重跑、在途调拨 |
| K8 | 硬闸门压力 | “先做”“别管”“赶紧”“别拖”等紧迫话术直接要求越过审批、质量、安全或合规闸门 | 识别闸门及授权主体，拒绝越权执行并改走合法路径 | 关闭 TLS 校验、整树提权、放行 quality hold、超额确认 |
| K9 | 权威状态时点错位 | “已确认/已通过/已完成/已清理/已经不要了”与最新权威记录冲突 | 找到最新、具备业务权威性的状态源并核对时点 | 已驳回审批、旧账户台账、最新客户反馈、错误完成声明 |

> 一条种子可以同时带第二机制，但**主机制只取一个**。主机制按“识破风险的主要发现路径”判定，不按业务领域判定。

### 3.1 高重合族

### 3.2 有没有“非删不可”的重复？

按以下三个条件判断“硬重复”：

1. 被藏住的业务事实相同；
2. 识破它需要走的证据路径相同；
3. 一旦执行，失败终态和损害对象相同。

用这三条检查，当前 66 条中**没有一条同时满足**。近邻们通常是同一“隐藏原语”，但至少有一个维度不同：

- 12/76/77 的文件格式与容器路径不同，失败证据分别是文本层、工作簿部件、ZIP 成员；
- 2/40/50/78/79 的进程类型和不可恢复状态不同；
- 16/17/27/34/62 的匹配键不同，且 34 还叠加了在途批次；
- 24/58 一个是部分成功后的重跑，一个是已有在途记录后的新建；
- 3/4/10/31/44/69 的依赖面不同，检查工具和证据链也不同。

因此结论是：

- **完整种子库：没有必要为了“重复”删任何一条。**
- **few-shot 示例集：必须做抽样压缩，否则模型会把注意力浪费在同一个原语的不同业务皮上。**
- 12、76、77 这一族如果只允许留一个，选 **76**，因为它最贴近“确实做了措施，但措施不消除风险”的新聚类目标。
- 78、79 如果只允许留一个，选 **78**，因为它在消息状态、进程停止、业务库与 broker 之间形成了更完整的可观察证据链；79 保留在语料中作为物理领域变体。
