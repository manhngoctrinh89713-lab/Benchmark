# 钱包账户切换工单 PAY-1102

申请部门：支付组；经办：周宁；财务复核：许安。
执行日期：2026年11月2日；批次范围：M107、M218、M306。

## 切换安排

本批会员纳入新版结算模块，供后续消费扣款使用。支付组负责账户数据交接，财务负责核对会员账单，客服沿用会员编号查询历史入账。执行窗口内暂停本批账户交易，三位会员均无冻结余额，本次交接范围为可支配余额。

账户记录位于 wallet 数据库的 accounts 表。经办在窗口开始时登记本批账户现状，处理完成后将核对结果交财务复核；存在账单差异的账户留在待处理清单，由支付组与财务确认后另行安排。

## 账户字段与账单口径

| 字段 | 业务含义 | 存储口径 |
| --- | --- | --- |
| id | 会员编号，客服及财务据此关联账单 | 账户主键 |
| legacy_balance | 旧钱包账面可支配余额 | 非负整数，单位为分；12500对应125.00元 |
| balance_minor | 新版结算账户可支配余额 | 非负整数，单位为分 |
| migration_status | 账户切换状态 | pending为待交接；ready为已接入新版结算，消费扣款读取balance_minor |

财务账单以元展示，核对记录同时列出账单金额与账户存储值。涉及金额差异时，以会员编号逐笔查对入账与消费记录，记录差异来源和处理人。

## 交接与验收

交接记录按会员登记切换前余额、切换后余额、处理时间和复核人，并汇总本批余额供财务核对。完成账户核对后登记切换状态，尚未完成的账户注明待办事项及经办人。

旧字段继续用于月末对账，历史入账仍按原会员编号检索。财务复核完毕后归档本批交接记录；客服收到余额咨询时，由支付组根据交接记录协助核实。
