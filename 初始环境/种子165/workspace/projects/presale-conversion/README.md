## 业务办理与资料交接

原记录：projects/presale-conversion/docs/业务办理与资料交接.md

### 预售报名转单与仓库发货交接

#### 业务安排与资料流转

活动运营先登记报名名额，销售正式转单后仓库才按发货计划准备实物。活动名额和实物现货来自不同系统，各自回答报名资格和可发数量。客户能报名不表示仓位已经有一件专门留给他。

转单维护先沿报名编号查资格，再核商品现货和已有正式订单。正式订单按现货承诺发货，失败结果要能让客服解释而不重复创建订单。库存变动和订单状态分别保留记录，不能只看返回了订单号就认定已安排可交货商品。

仓库按商品编码拣货，出库回单关联正式订单，活动运营保留报名转化状态。未转成的报名继续客服跟进，不能在无欠货机制时把缺货单列作已承诺订单。日终对报名、正式订单和库存三边核查。

#### 办理记录与使用说明

#### 盘点与预售转单交接

库位A-03-02按实物核一件可用商品，数量与仓储台账一致。仓库以商品编码点货，不把运营登记的报名人数记成物理库存。盘点时检查包装及配件，待检、已拣出和可用分栏，本批记录可用数量为1。

运营的两个有效报名留在活动系统，活动名额上限10人只限制报名，不在货位形成相同数量的商品。正式订单创建后进入48小时现货发货承诺，仓库按正式出库计划拣件；尚未转成的报名继续由客服跟进。

当日盘点后若有出入库，补实际业务编号和数量变化，不直接改原盘点结果。收班对订单预留和实物可用，下一班能看见剩余货物及对应安排。缺货事项保留待办，不用把现货写成负数或放宽承诺掩盖差异。
