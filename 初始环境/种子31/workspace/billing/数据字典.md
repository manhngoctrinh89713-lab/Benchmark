# billing 库字段说明

| 表.字段 | 类型 | 说明 |
| --- | --- | --- |
| invoices.amount_minor | 整数 | 含税金额，单位分 |
| invoices.legacy_tax_code | 文本 | 2024 年起停用，新数据由 tax_code 取代 |
| invoices.tax_code | 文本 | 13 位商品编码，新发票只写该字段 |
| invoices.status | 文本 | settled 表示已结算 |

历史发票保留 legacy_tax_code 原值。新发票的 legacy_tax_code 为空。
