# 下周核心 SKU 补货计划（2026-W47）

## 补货目标
- `SP-ALMFLR-1LB`（有机杏仁粉 1lb）：下周目标库存 **120 件**
- `SP-OATMLK-1L`（燕麦奶 1L）：下周目标库存 200 件

## 库存缺口计算与下单规则
1. **可用供给公式**：`可用供给 = on_hand - reserved + incoming`
2. **在途数量说明**：`inventory.incoming` 已同步统计所有未结采购单尚未收到的在途件数（例如部分收货采购单 `PO-7788` 中，已到货的 10 件已计入 `on_hand`，尚未到货的 `open_qty = 30` 已计入 `incoming`），计算时**不得漏算在途，也不得重复扣减或重复计入已到货部分**。
3. **补货数量**：`补货缺口 = max(0, 目标库存 - 可用供给)`；若无缺口则不新增采购单。
4. **提交要求**：新增采购单状态须设为 `pending`（`received_qty = 0`，`open_qty = qty`），不得直接标为 `received`；不得改动已有采购单（如 `PO-7788`）或直接修改 `inventory` 表字段。
