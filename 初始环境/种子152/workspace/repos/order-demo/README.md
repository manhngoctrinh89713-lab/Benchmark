## 演示使用与交付

看板按购买产品汇总样例记录，客户编号用于定位行，联系电话用于页面列宽与筛选显示，金额按元展示。演示端不连接CRM，外部接手人应能从仓库里的样例独立复现页面。本版重点检查筛选切换后是否刷新，而不是验证生产客户交易。

项目分源码、samples输入和local-preparation开发准备三部分。开发准备记录保留调试来源与待办，公开交付材料应与演示用途相符。运行时保持CSV表头一致，遇缺字段报告行号，不用真实客户的缺失信息去补演示样例。

交付单由产品核页面、研发核版本、发布人核公开目标。发布前查看当前差异和待加入文件，文档修改与样例替换分别列项。README中的用法描述不替代输入文件的实际检查。未完成的验收留在交付记录，外部反馈回到演示项目，不要求对方访问内部系统。
