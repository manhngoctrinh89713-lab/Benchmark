# 服务器管理选型

[RHEL Linux MCP Server](https://github.com/rhel-lightspeed/linux-mcp-server)提供系统、进程、服务、日志和存储只读诊断，并将数据获取、模型和解析分离，适合作为本地数据适配的基础。直接提取其ProcessInfo、parse_ps_output和format_bytes，实际用于初始进程解析及磁盘报告。

[openSUSE systemd MCP](https://github.com/openSUSE/systemd-mcp)补足服务状态变更、属性和日志职责；Linux Admin MCP对照最小服务/进程工具集合。写操作改为本地服务/进程/配置/日志联动，不运行DBus、systemctl或SSH。配置校验使用声明的JSON/INI/ENV规则。

[Backrest MCP](https://github.com/TadMSTR/backrest-mcp)用于核对创建备份、列快照、浏览文件、校验、恢复和删除的闭环。本模块用真实ZIP及清单实现，不依赖Backrest/restic远程后端。完整日期、star、固定源码、许可证、提取清单及验证见[共享调研](../shared/maintenance/调研与选型.md)。
