# 工具清单

| 工具 | 功能 |
| --- | --- |
| [server_analyze_directory](工具调用API/server_analyze_directory/README.md) | 按Linux绝对路径分析真实场景文件的大小、数量和大文件。 |
| [server_change_service](工具调用API/server_change_service/README.md) | 模拟start/stop/restart/reload/enable/disable，联动进程和日志；启动校验配置及依赖。 |
| [server_create_backup](工具调用API/server_create_backup/README.md) | 将登记备份范围内的服务配置或数据文件写入真实ZIP与清单。 |
| [server_delete_backup](工具调用API/server_delete_backup/README.md) | 删除本地备份归档及登记，释放模拟磁盘空间。 |
| [server_get_disk_usage](工具调用API/server_get_disk_usage/README.md) | 读取模拟挂载点的基础、真实配置/日志/数据文件及备份占用。 |
| [server_get_permissions](工具调用API/server_get_permissions) | 读取服务器路径的所有者、用户组和权限模式；递归时包含整棵子树。 |
| [server_set_permissions](工具调用API/server_set_permissions) | 调整服务器路径的所有者、用户组和八进制权限模式；可递归应用于整棵子树。 |
| [server_reboot](工具调用API/server_reboot) | 模拟重启整机：停止本机服务并记录重启事件。 |
| [server_get_process](工具调用API/server_get_process/README.md) | 读取场景PID详情、服务关联及资源，包含已终止进程。 |
| [server_get_service](工具调用API/server_get_service/README.md) | 读取服务启用/运行状态、主PID、依赖及磁盘配置与生效配置的哈希差异。 |
| [server_get_system_info](工具调用API/server_get_system_info/README.md) | 读取模拟Linux系统、资源、磁盘及失败服务概况。 |
| [server_list_backups](工具调用API/server_list_backups/README.md) | 分页列出当前服务器的本地备份记录。 |
| [server_list_processes](工具调用API/server_list_processes/README.md) | 搜索当前进程命令并排序；初始进程由提取的Linux MCP ps解析器读入。 |
| [server_list_services](工具调用API/server_list_services/README.md) | 按active/inactive/failed和名称搜索本服务器的systemd服务。 |
| [server_prune_logs](工具调用API/server_prune_logs/README.md) | 预览或删除指定服务较早的日志，保留最新keep_last条；其他服务日志保持不变。 |
| [server_query_logs](工具调用API/server_query_logs/README.md) | 查询真实场景JSONL日志；优先级0最严重，筛选0..max_priority，结果按时间倒序。 |
| [server_read_file](工具调用API/server_read_file/README.md) | 读取登记挂载点内的UTF-8场景文件、大小和哈希；最多200000字节。 |
| [server_read_service_config](工具调用API/server_read_service_config/README.md) | 读取登记服务配置的真实UTF-8文本和SHA-256，不读取宿主机/etc。 |
| [server_restore_backup](工具调用API/server_restore_backup/README.md) | 从校验后的ZIP恢复原路径；覆盖需显式指定，配置恢复后仍须重新加载服务。 |
| [server_signal_process](工具调用API/server_signal_process/README.md) | 向模拟进程发送TERM/KILL/STOP/CONT；主进程终止会使关联服务失败并写日志。 |
| [server_validate_service_config](工具调用API/server_validate_service_config/README.md) | 按场景声明的JSON/INI/ENV语法和必填字段规则校验真实配置；不运行服务二进制。 |
| [server_verify_backup](工具调用API/server_verify_backup/README.md) | 验证ZIP整体及逐文件哈希、机器身份和恢复路径。 |
| [server_write_service_config](工具调用API/server_write_service_config/README.md) | 按原文件哈希保存待生效配置；允许先保存错误配置，校验及reload/restart另行调用。 |
