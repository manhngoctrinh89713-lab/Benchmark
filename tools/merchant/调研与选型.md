# 商家工具选型

共同版本、许可证和源码核对见[共享调研](../shared/commerce/调研与选型.md)。商家工具主要参考PayPal MCP的商品、订单、收款、退款、订阅计划与订阅职责，以及Stripe账单/付款/退款的业务划分。

保留21个常用工具，适配本地库存、订单履约、退款审批和显式计费，不引入任意远程API执行、账户凭证、银行划拨或真实支付。订单金额明细复用共享包中的PayPal提取函数，商家读取的是买家结算时产生的同一订单快照。

本目录只公开商家管理操作。工具绑定构造时选定的商家，按merchant_id隔离订单、付款和订阅；不提供买家付款工具。完整工具表及运行规则见[商家说明](../../prompt/tools/merchant.md)。
