# 工具清单

| 工具 | 功能 |
| --- | --- |
| [pc_analyze_directory](工具调用API/pc_analyze_directory/README.md) | 分析登记磁盘内目录的真实场景文件大小、数量和大文件。 |
| [pc_change_process](工具调用API/pc_change_process/README.md) | 挂起、恢复或终止指定模拟进程；保护系统进程，不使用宿主机PID。 |
| [pc_clean_cache](工具调用API/pc_clean_cache/README.md) | 预览或清理登记缓存中的过期文件，跳过模拟进程正在使用的文件。 |
| [pc_create_backup](工具调用API/pc_create_backup/README.md) | 将登记个人文件备份为真实ZIP及校验清单；支持幂等重试。 |
| [pc_delete_backup](工具调用API/pc_delete_backup/README.md) | 删除一个本地ZIP备份和记录，释放模拟备份磁盘空间。 |
| [pc_delete_personal_file](工具调用API/pc_delete_personal_file/README.md) | 按预期哈希删除一个个人文件；模拟进程使用中的文件不能删除。 |
| [pc_get_disk_usage](工具调用API/pc_get_disk_usage/README.md) | 按模拟卷统计系统基础占用、应用、真实场景文件和ZIP备份占用。 |
| [pc_get_process](工具调用API/pc_get_process/README.md) | 读取指定场景PID的状态、应用关联、资源和打开文件；含已终止记录。 |
| [pc_get_system_info](工具调用API/pc_get_system_info/README.md) | 读取场景Windows电脑的系统信息、内存、进程和磁盘概况。 |
| [pc_launch_application](工具调用API/pc_launch_application/README.md) | 为已安装应用创建本地模拟进程；不执行其命令或程序。 |
| [pc_list_applications](工具调用API/pc_list_applications/README.md) | 搜索应用目录；默认只看已安装应用，可查询可安装版本和占用。 |
| [pc_list_backups](工具调用API/pc_list_backups/README.md) | 分页列出当前电脑的备份记录及归档哈希。 |
| [pc_list_cache_locations](工具调用API/pc_list_cache_locations/README.md) | 列出可清理的登记缓存位置、实际文件数量和占用。 |
| [pc_list_personal_files](工具调用API/pc_list_personal_files/README.md) | 在登记个人文件根内分页列出真实文件、大小和哈希。 |
| [pc_list_processes](工具调用API/pc_list_processes/README.md) | 按名称搜索当前进程并按内存、CPU或PID排序；使用提取的上游进程过滤逻辑。 |
| [pc_list_startup_items](工具调用API/pc_list_startup_items/README.md) | 列出模拟Windows开机启动项、来源、应用和启用状态。 |
| [pc_manage_application](工具调用API/pc_manage_application/README.md) | 在本地状态中安装、更新或卸载登记应用；运行中应用须先退出，磁盘占用同步变化。 |
| [pc_read_personal_file](工具调用API/pc_read_personal_file/README.md) | 读取登记个人文件中的UTF-8文本及原始字节SHA-256。 |
| [pc_restore_backup](工具调用API/pc_restore_backup/README.md) | 从已校验ZIP恢复原个人文件；默认拒绝覆盖，可幂等重试。 |
| [pc_set_startup_item](工具调用API/pc_set_startup_item/README.md) | 启用或禁用登记启动项；不修改真实注册表或启动文件夹。 |
| [pc_verify_backup](工具调用API/pc_verify_backup/README.md) | 校验ZIP整体哈希、清单、逐文件内容和恢复路径范围。 |
| [pc_write_personal_file](工具调用API/pc_write_personal_file/README.md) | 创建或更新个人文本文件；更新必须提供原字节哈希以防覆盖其他修改。 |
