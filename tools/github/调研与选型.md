| 本地功能 | 上游参考 | 适配方式 |
| --- | --- | --- |
| get_me | README中的get_me | 读取场景current_user/users；未宣称直接复用用户Go实现 |

| Issue三工具 | issues.go的读取、列表、写入 | JSON任务数据，新增编号与PR共享，补入标签及里程碑校验 |

| list_notifications/mark_notification_read | notifications.go的ListNotifications、DismissNotification | 读取当前用户通知，将state=read收敛为独立工具 |

这里复用的是官方工具职责、参数和协作流程；Go服务的认证、HTTP/GraphQL和远程业务后端未复制或执行。本地适配代码由本项目实现。直接源码提取发生在共享Git读取层，已单独提供逐函数来源记录，不能将此描述为直接移植了GitHub全部实现。

31个工具覆盖发现代码、可见性、任务分类、分支PR、评审合并、CI诊断、发布和通知处理。没有引入真实账号权限、Actions执行、外部通知、Copilot、Secrets或组织管理。详细边界见[子模块说明](../../prompt/tools/github.md)。
