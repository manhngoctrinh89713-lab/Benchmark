# 买家工具选型

共同版本、许可证和源码核对见[共享调研](../shared/commerce/调研与选型.md)。买家工具参考Shopify当前UCP的商品搜索、完整购物车替换、结算和订单查询流程，结合PayPal订单付款和订阅创建/取消职责。

保留21个工具，形成浏览、购物车、结算、付款、订单查询、退款申请、订阅与账单补付的完整本地流程。购物车不预留库存，结算校验当前价格并保留商品快照；支付结果由场景配置，避免把所有调用都模拟成成功。

买家只能操作自己的交易对象和支付方式，可以申请退款但不能审批或直接执行商家退款。真实JSON收据、付款尝试和商家履约信息都来自共享账本。完整工具表见[买家说明](../../prompt/tools/buyer.md)。
