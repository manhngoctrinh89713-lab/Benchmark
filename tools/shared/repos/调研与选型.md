## 模拟边界

Git和GitHub共用本地仓库；push/fetch 通过本地 state 中的 remote refs 和 `refs/remotes/...` 模拟，不建立真实远程副本、不做网络传输。GitHub读已提交版本；Git工作区可以有未提交修改。Actions及通知由场景预置，不执行CI、不自动生成成功结论、不向他人发送消息。Release只保存本地元数据及tag，包括草稿，不上传资产。逐行评审只支持当前差异块RIGHT侧，不覆盖完整线程生命周期。

选择范围覆盖找代码、整理任务、开发提交、评审合并、CI诊断及版本发布，未引入Copilot、组织管理、Secrets、计费或真实外部服务。验证脚本覆盖47个工具、跨模块关联与恢复，见README。
