# 微信式聊天模型：调研与改动

2026-11-01。本模块以微信式私聊、群聊和本地聊天记录为产品模型。MCP只是可复用代码或接口参考的来源，各平台有的功能不会自动进入工具集。

## 补充调研

| 项目 | 核对到的实用能力 | 本轮采用方式 |
| --- | --- | --- |
| [xerlxzx/Wechat-MCP](https://github.com/xerlxzx/Wechat-MCP) | 本地历史只读桥接；会话、联系人、群信息、消息搜索、上下文、附件查询和获取 | 核对查询与文件数据模型；真实实现依赖Mac微信历史归档，不接入真实数据库 |
| [lw396/wechat-mcp](https://github.com/lw396/wechat-mcp) | 基于WeChatFerry，工具包含联系人、文本/文件发送和消息转发；mcp_server.go定义转发消息ID和目标接收者 | 以实际微信MCP的逐条转发接口为参考，添加forward_message；不引入DLL、Go或登录依赖 |
| [thisnick/agent-wechat](https://github.com/thisnick/agent-wechat)及[消息类型说明](https://thisnick.github.io/agent-wechat/how-it-works/message-types/) | 引用的正文与quote分开表达，提供撤回能力，由客户端判断是否可撤回 | 核对引用和撤回是两种独立操作，引用保持在普通聊天记录中。只作接口语义参考，不复制实现 |

新增固定来源文件、commit、SHA-256见公用代码/research_metadata.json；新下载的源码均不参与运行。lw396页面star快照约18（2026-11-01），本轮依据其具体转发功能选入参考，不以star排序。公开微信帮助页本轮访问失败，各版本撤回限制也存在差异，因此不把检索到的传闻或企业微信规则写成个人微信事实：本地明确采用案例可配置的撤回窗口，默认120秒。

## 逐工具改动

| 工具 | 决定及当前语义 |
| --- | --- |
| search_contacts | 保留；姓名、联系人备注、微信号、电话等检索 |
| list_chats | 保留；仅私聊与群聊 |
| get_chat | 保留；chat_jid改chat_id；增加群主，未读为本地状态 |
| list_messages | 保留；基于当前用户本地记录检索，撤回保留提示，本地删除不可见 |
| get_message_context | 保留；同会话前后文，没有独立线程 |
| get_thread | 删除，移除线程数据和根消息逻辑 |
| edit_message | 删除；不提供直接修改已发消息的能力 |
| set_reaction | 删除；不提供附着在消息上的Slack式表情回应 |
| send_message | 修改；reply_to改quote_message_id，并支持群成员mention_ids |
| send_file | 修改；发送独立文件消息，取消文件caption与reply_to参数 |
| download_media | 保留；获取当前本地记录中仍可访问的附件 |
| delete_message | 修改；仅本地删除，可删除他人消息，不再代表撤回 |
| recall_message | 新增；限时撤回本人消息，保留提示和历史发送快照 |
| forward_message | 新增；逐条转发文本或文件，复制字节、不继承@及引用 |
| create_chat | 修改；只建私聊或群聊，新群至少三人，显式群主 |
| update_chat_members | 修改；普通成员可在无需审批时邀请，移除限群主/管理员 |
| mark_read | 修改；清整个会话的本人未读，不暴露其他人的阅读信息 |

最终14个工具。群公告、收藏、置顶、免打扰、合并转发、添加好友及群审批流程未进入首版，避免没有任务需求就扩大模拟范围。@所有人、语音特殊行为和各版本平台限额也不冒充完整复刻。

## 代码复用边界

保留WhatsApp MCP中search_contacts/list_chats/get_chat/get_message_context的4个入口转发结构，替换后端绑定和工具说明，get_chat参数统一为chat_id。提取脚本和hash记录随改动同步。提取入口不决定产品行为，后端统一为微信式模型。

其他10个工具为文件数据适配，不宣称从微信MCP完整提取真实业务后端。此前Telegram、Slack、飞书、Discord的调研快照保留在upstream供追溯，其功能集合不再作为当前接口规范。共享持久化仍沿用本项目邮件模块。

## 验证

检查覆盖全部14个FastMCP调用与schema一致性、本地删除和撤回差异、撤回本人权限及超时、撤回提示、平铺引用与跨会话引用拒绝、群内@与私聊拒绝、逐条文件转发及源消息删除后的独立性、群主/管理员保护、本地未读和无已读回执、不可见群隔离。旧混合模型不自动迁移，明确要求model_version=2与新运行编号。
