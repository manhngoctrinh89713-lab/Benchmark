固定commit：

- Desktop Commander：`9a171d1dae74de94bf07e6e13878006fb69fa600`。核对README、LICENSE及src/tools/edit.ts的performSearchReplace，包括原文读取、预期次数、换行适配和模糊匹配流程。

Serena当前版本按组件授权：SolidLSP为MIT，Serena应用为GPL-3.0-or-later，不能沿用旧调研中“整个Serena是MIT”的说法。权威说明见该固定版本的[LICENSE](https://github.com/oraios/serena/blob/ede329aaf0c824bea75455a2926f01420d7aa620/LICENSE)。本模块只参考工具职责，没有提取或链接Serena应用源码，原始快照保留其完整许可证；运行包也未引入SolidLSP。

实际直接复用的是Tree-sitter MCP的functions/classes/structs/interfaces/enums/traits查询模板子集。extract_cores.py通过AST读取原TEMPLATES常量，生成local_code/symbol_queries.json。修正C++方法定义节点、Java接口/构造器体、TypeScript接口体，并补充JavaScript方法查询。原项目的部分查询与固定语法不匹配，不能仅据功能表宣称可用；最终查询均已编译并在真实示例上提取符号。

运行时使用tree-sitter 0.25.2和自带语法的tree-sitter-language-pack 0.13.0，不照搬上游服务对旧tree-sitter的依赖上限。解析、查询和语法错误都来自真实语法树；文件选择、分页、包装节点范围、嵌套name_path、Unicode列号和编辑发布由本模块适配。

Python语义查找和重命名使用[Jedi官方API](https://jedi.readthedocs.io/en/v0.19.2/docs/api.html)的Script.get_references和Script.rename。固定0.19.2，由其生成跨文件改动，不用文本搜索冒充语义引用；重构输出不直接让Jedi落盘，而统一经过项目路径、原哈希、语法校验和文件记录发布。

持久化直接复用本项目第2类FileStore的初始化、边界检查、快照、文件锁和pending恢复机制。internal_sources保存当时源码，提取后改名CodeState，运行时不导入文件管理模块或MarkItDown。EXTRACTION.json分别记录上游查询和内部持久化的源/输出hash、提取范围及修改说明。

## 工具组合

最终16个工具：项目和文件发现2个，读取/搜索2个，符号概览/查找/引用3个，语法诊断1个，创建/精确替换/行编辑3个，符号替换/相邻插入2个，Python重命名1个，批量文件修改1个，初始基线变更比较1个。

代码生成由调用者提供content/body，工具负责写入、定位、修改和校验，不再接一个代码生成服务。保留通用文本修改以处理配置或不完整语法，结构编辑默认检查语法。通用终端、任意脚本执行、语言服务器安装、缓存/提示词/记忆管理不纳入这套工具。版本协作沿用第5类Git模块。
