# Git子模块调研

主来源为[modelcontextprotocol/servers Git MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/git)，MIT，固定commit `194cc86e3ae6400958555bd4116849d822d69263`。2026-11-01页面约91.7k star，代表整个servers仓库。

直接提取的4个函数保存在父级共享包`local_repos/git_reads.py`，其中3个读取函数组成git_status和git_diff。提取脚本、原始快照、许可证及EXTRACTION.json均保留在父级公用代码，避免两个子模块重复维护。其余Git操作以系统Git实现，接入本地事务及仓库边界检查。

Git模块选择16个工作区、版本、分支和本地远程模拟工具；Issue、PR和Release移交GitHub模块。两个子模块的关联、候选比较和取舍见[完整调研](../shared/repos/调研与选型.md)。
